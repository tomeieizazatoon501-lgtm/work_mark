# 7 Day Escape

ต้นแบบเกมฝึกเอาชีวิตรอดจากภัยพิบัติ อ้างอิงแนวคิดจากเอกสารเกม 7 Day Escape
ทำด้วย Flutter และรองรับการรันบนเว็บและมือถือ

## เดโมที่เล่นได้

หน้าแรกแยกโหมดเป็น 2 ช่อง:

1. **มินิเกมหนีออกจากอาคาร** — มุมมองจากด้านบนในห้องโล่ง ลาก Virtual Joystick
   360° หรือใช้ WASD ตามลูกศรไปยังประตู แล้วเข้าสู่ช่วงวิ่งฝ่าซาก 6 ชิ้น
   ก่อนแตะประตู ESCAPE เพื่อจบด่าน Day 1
2. **พัซเซิลตอบคำถาม** — แบบฝึกตัดสินใจ 3 สถานการณ์เกี่ยวกับไฟ น้ำท่วมใกล้อุปกรณ์ไฟฟ้า
   และแผ่นดินไหว พร้อมคะแนนและคำอธิบายหลังเลือกคำตอบ

สถานการณ์ทั้งหมดเป็นแบบจำลองเพื่อการเรียนรู้ ไม่แทนคำแนะนำจากหน่วยงานฉุกเฉิน

## เริ่มต้นใช้งาน

```shell
flutter pub get
flutter run -d chrome
```

ตรวจสอบโปรเจกต์และรัน widget tests:

```shell
flutter analyze
flutter test
```
